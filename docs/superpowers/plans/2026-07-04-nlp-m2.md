# NLP M2 — Language Expansion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expand Fabulous Writing to seven languages (en, de, fr, es, it, ja, zh) with a `GET /api/languages` endpoint, CJK-correct terminology matching, token-count occurrence rules, and starter rule sets — M2 of `docs/superpowers/specs/2026-07-04-nlp-rule-engine-design.md`.

**Architecture:** The `Language` enum grows to seven members (backend pydantic + frontend TS union). A new `/api/languages` endpoint reports per-language NLP availability from `NlpRegistry` without loading models (installed-package check). Terminology matching for ja/zh switches from `\b` regexes to spaCy `PhraseMatcher` with a substring fallback. `occurrence` rules gain `count: tokens`, which makes them doc-dependent (skipped + reported like NLP rules when the model is missing).

**Tech Stack:** spaCy 3.8 (PhraseMatcher), GiNZA/ja_ginza (compatible: ginza 5.2.0 allows spacy <4.0; SudachiPy 0.6.9 and spacy-pkuseg 1.0.1 ship cp313 wheels), zh_core_web_sm 3.8.0, FastAPI, React/TS.

**Pre-verified facts (2026-07-04):**
- `ginza` 5.2.0 requires `spacy<4.0.0,>=3.4.4` → OK with our spaCy 3.8.14.
- `SudachiPy` 0.6.9 has cp313 macOS universal2 wheels; `spacy-pkuseg` 1.0.1 has cp313 arm64 wheels.
- Dev-dep models per spec §F: EN, DE, JA, ZH. FR/ES/IT models are NOT dev deps; their nlp_available is false in dev, which is fine (their starter rules are regex-only).

```python
def _check_token_count(rule: LoadedRule, ctx: CheckContext) -> list[Finding]:
    spec = rule.spec
    if ctx.doc is None:
        return []
    findings: list[Finding] = []
    for start, end, sentence in split_sentences(ctx.text, doc=ctx.doc):
        span = ctx.doc.char_span(start, end, alignment_mode="expand")
        count = sum(1 for t in span if not t.is_punct and not t.is_space)
        too_many = spec.max is not None and count > spec.max
        too_few = spec.min is not None and count < spec.min
        if too_many or too_few:
            findings.append(Finding(category=spec.category, severity=spec.level,
                                    source=Source.RULE, rule_id=rule.rule_id,
                                    message=spec.message,
                                    span=Span(start=start, end=end, text=sentence)))
    return findings
```

```python
CJK_LANGUAGES = {Language.JA, Language.ZH}


class TerminologyChecker:
    def __init__(self, store: TerminologyStore, nlp: "NlpRegistry | None" = None) -> None:
        self.store = store
        self.nlp = nlp

    def check(self, text, language, domain_id):
        terms = self.store.list_terms(domain_id, language=language)
        if language in CJK_LANGUAGES:
            findings = self._check_cjk(text, language, terms)
        else:
            findings = self._check_regex(text, terms)
        findings.sort(key=lambda f: (f.span.start, f.span.end))
        return findings
```

`_check_regex` = existing body extracted. `_check_cjk`:

```python
def _check_cjk(self, text, language, terms):
    pipeline = self.nlp.get(language.value) if self.nlp else None
    if pipeline is None:
        return self._check_substring(text, terms)   # documented fallback
    from spacy.matcher import PhraseMatcher

    doc = pipeline.make_doc(text)  # tokenization only
    findings = []
    for attr, case_sensitive in (("ORTH", True), ("LOWER", False)):
        group = [t for t in terms if t.case_sensitive is case_sensitive]
        if not group:
            continue
        matcher = PhraseMatcher(pipeline.vocab, attr=attr)
        variants: list[tuple[object, str]] = []
        for term in group:
            for variant in term.forbidden_variants:
                matcher.add(str(len(variants)), [pipeline.make_doc(variant)])
                variants.append((term, variant))
        for match_id, start, end in matcher(doc):
            term, _variant = variants[int(pipeline.vocab.strings[match_id])]
            span = doc[start:end]
            findings.append(self._finding(term, span.text, span.start_char, span.end_char))
    return findings


def _check_substring(self, text, terms):
    findings = []
    for term in terms:
        for variant in term.forbidden_variants:
            haystack = text if term.case_sensitive else text.lower()
            needle = variant if term.case_sensitive else variant.lower()
            pos = haystack.find(needle)
            while pos != -1:
                findings.append(self._finding(term, text[pos:pos + len(needle)], pos, pos + len(needle)))
                pos = haystack.find(needle, pos + 1)
    return findings
```

`_finding(term, matched, start, end)` = extracted Finding construction (message with preferred + optional definition, suggestions=[term.preferred]).
